ForecastBaselines.jl

ForecastBaselines.jl fits baseline forecasting models to univariate time series, produces point forecasts and prediction intervals from them, and scores the forecasts against what was observed. Every model, from carrying the last value forward to exponential smoothing, is fitted with fit_baseline and forecast with forecast, so models can be swapped without changing the code around them.

The package provides:

  • ten models: constant, marginal, kernel density, last similar dates, polynomial trend (OLS), increase–decrease–stable, ARMA, INARCH for counts, STL decomposition and all 30 ETS variants (see Models);
  • prediction intervals from past forecast errors (EmpiricalInterval), the model's own forecast distribution (ParametricInterval) or simulated trajectories (ModelTrajectoryInterval);
  • data transformations and seasonal-trend preprocessing that wrap any model (transform, STTransform);
  • point and interval scores, and calibration measures for evaluating forecasts (score, CvM_divergence).

Installation

ForecastBaselines.jl is in the Julia General registry:

using Pkg
Pkg.add("ForecastBaselines")

To use the development version instead:

Pkg.add(url = "https://github.com/epiforecasts/ForecastBaselines.jl")

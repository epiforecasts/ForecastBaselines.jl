Getting started

This page fits a model to a simulated monthly series, forecasts from it with each interval method, and compares three models on forecasts made from earlier stretches of the same series.

Fitting and forecasting

The series has a slow upward trend, a yearly cycle and noise.

using ForecastBaselines, Random
Random.seed!(1)
n = 120
y = [20 + 0.1t + 5sin(2π * t / 12) + 2randn() for t in 1:n]

A model specification holds the model's structure but no data. fit_baseline estimates its parameters, and forecast projects the fitted model forward over the requested horizons, with prediction intervals at the requested levels.

fitted = fit_baseline(y, ARMAModel(p = 1, q = 1))
fc = forecast(fitted; interval_method = ParametricInterval(), horizon = 1:6, levels = [0.5, 0.9])

The forecast stores the point forecasts in fc.mean and one ForecastInterval per horizon in fc.intervals:

Models fitted by numerical optimisation (ARMA, INARCH and ETS) record whether the optimiser converged. A fit that stopped at the iteration limit gives a warning once per model type, and has_converged reports it for each fit:

has_converged(fitted)
true

Prediction intervals

Three methods produce prediction intervals, and NoInterval gives point forecasts only. ParametricInterval, used above, uses the model's own forecast distribution: in closed form for ARMA, OLS and IDS, and from quantiles of the past data, or of its estimated density, for the marginal, KDE and LSD models. ModelTrajectoryInterval simulates future paths from the fitted model, and EmpiricalInterval refits the model on shorter stretches of the series and resamples the errors those fits made. Empirical intervals work for every model, but take longer, as they refit the model many times. Here are the 90% intervals one step ahead from each of the three methods:

parametric = forecast(fitted; interval_method = ParametricInterval(), horizon = 1:6, levels = [0.9])
simulated = forecast(fitted; interval_method = ModelTrajectoryInterval(n_trajectories = 1000, seed = 1), horizon = 1:6, levels = [0.9])
empirical = forecast(fitted; interval_method = EmpiricalInterval(seed = 1), horizon = 1:6, levels = [0.9])
[(f.intervals[1].lower[1], f.intervals[1].upper[1]) for f in (parametric, simulated, empirical)]
3-element Vector{Tuple{Float64, Float64}}:
 (26.737072447621316, 38.344708207036945)
 (26.853669414270023, 38.26437341888605)
 (27.00317346481411, 39.295562304926904)

Models lists which interval methods each model supports.

Transformations and seasonality

transform wraps a model so that it is fitted to transformed data and its forecasts are transformed back. A log transformation suits series that are positive and whose variation grows with their level:

log_arma = ForecastBaselines.transform(ARMAModel(p = 1, q = 1); transformation = LogTransform())
forecast(fit_baseline(y, log_arma); horizon = 1:6).mean
6-element Vector{Float64}:
 32.24579786700678
 30.545120096682616
 29.292741225244793
 28.36034723492946
 27.660292698236333
 27.13124109088212

STTransform removes a seasonal cycle, and optionally a trend, before fitting, and adds them back to the forecasts. This lets a model without seasonality of its own, here ConstantModel, forecast a seasonal series:

seasonal_constant = ForecastBaselines.transform(ConstantModel(); season_trend = STTransform(s = 12, trend = true))
forecast(fit_baseline(y, seasonal_constant); horizon = 1:6).mean
6-element Vector{Float64}:
 37.7458847230759
 39.74980266956031
 40.50809036511879
 39.843194553128654
 37.95890284849612
 35.385739010814845

Calling it as ForecastBaselines.transform avoids a clash with transform from DataFrames.jl when both packages are loaded.

Comparing models

To compare models, forecast from several points in the past and score each forecast against what was observed afterwards. add_truth attaches the observed values to a forecast, and score averages a scoring rule over a collection of forecasts.

models = [
    "Constant" => ConstantModel(),
    "ARMA(1,1)" => ARMAModel(p = 1, q = 1),
    "ETS(A,A,A)" => ETSModel(error = "A", trend = "A", season = "A", s = 12),
]
forecasts = Dict(
    name => [
            add_truth(
                forecast(
                    fit_baseline(y[1:origin], model);
                    interval_method = EmpiricalInterval(seed = 1), horizon = 1:6,
                    levels = [0.5, 0.8, 0.9]
                ),
                y[(origin + 1):(origin + 6)]
            )
            for origin in 72:6:(n - 6)
        ]
        for (name, model) in models
)
[(name, round(score(forecasts[name], MAE()); digits = 2), round(score(forecasts[name], WIS()); digits = 2)) for (name, _) in models]
3-element Vector{Tuple{String, Float64, Float64}}:
 ("Constant", 4.05, 8.67)
 ("ARMA(1,1)", 4.92, 9.71)
 ("ETS(A,A,A)", 2.29, 4.9)

The mean absolute error (MAE) scores the point forecasts and the weighted interval score (WIS) the intervals; lower is better for both. ETS, the only one of the three models with a seasonal component, does best on both.

CvM_divergence measures how far the forecasts are from being calibrated, that is how far the observations are from being spread across the forecast distributions as often as the distributions imply. It is zero for perfectly calibrated forecasts.

[(name, round(CvM_divergence(forecasts[name]); digits = 3)) for (name, _) in models]
3-element Vector{Tuple{String, Float64}}:
 ("Constant", 0.172)
 ("ARMA(1,1)", 1.721)
 ("ETS(A,A,A)", 0.155)
